# Security policy

Kin is a prototype intended for fictional hackathon records. Real patient use
requires a separate clinical, legal and operational review.

Report vulnerabilities using GitHub's private vulnerability reporting on this
repository when enabled. If it is unavailable, open an issue requesting a private
contact channel without publishing exploit details or sensitive records.

No response-time guarantee is offered. See [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md)
for implemented controls and known limits. Never include API keys, medical files,
share tokens or user details in public reports.
